# CONTEXT.md — Проект «Poker Mini App»

## 🎯 Цель проекта
Telegram Mini App для покера (в перспективе — дурак). Отдельный от бота шашек. Назначение — тренировка и «похвастаться» в дружеских играх на бесплатных платформах. НЕ для реальных денег. 

## 🏗️ Что уже сделано (Фактическое состояние на сегодня)
- **Сервер:** XorekCloud (Ubuntu 22.04). Всё работает в фоне через `systemd`, Termius можно закрывать.
- **Домен:** Куплен `pokerbot.cyou` (на 1 год). Привязан к Cloudflare (бесплатный тариф).
- **Туннель:** Cloudflare Tunnel (`cloudflared`) создан и работает как служба. Постоянная HTTPS-ссылка.
- **Веб-сервер:** Python `http.server` на порту 8091, работает как служба `pokerweb`. Раздает файлы из папки `/root/mini-water`.
- **Бот:** Новый тестовый бот `@MyTestPoker1983_bot` (отдельный токен, отдельный процесс). Присылает кнопку «🎴 Открыть покер».
- **Mini App:** Белая страница `index.html` с текстом «Привет, Покер!» успешно открывается и в браузере, и внутри Telegram по адресу `https://pokerbot.cyou`.

## 🖊️ Ввод состояния (через Mini App)
Мы отказались от кнопок в чате (FSM) в пользу одного экрана (Дашборд), так как это быстрее и удобнее.
- **Экран:** Темная тема, зеленое сукно. Сетка карт (ранг + масть), кнопки позиции, поле борда, кнопки действий.
- **Вывод совета:** Крупно, контрастно. Действие (RAISE/CALL/FOLD) + одна причина.
- **Альтернатива:** В будущем можно добавить вкладку «Чарты» с картинками (как в старом контексте), но пока фокус на ручном вводе.

3. **Мозг на сервере:** Обновить `bot.py` или создать `server.py` (чтобы принимать данные из App и отдавать совет-заглушку).
4. **Интеграция движка:** Подключить `PokerKit` и API OpenAI.
5. **Тестирование:** Запустить реальную раздачу с друзьями.
